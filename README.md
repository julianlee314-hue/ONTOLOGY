# ONTOLOGY Kanban (public view)

A sticky-note Kanban board of Julius's ONTOLOGY projects, grouped by realm (EDUCATION, LIFE, MEDIA, TOOLS), big project and sub-card.

**Live:** https://julianlee314-hue.github.io/ONTOLOGY/

- Plain HTML/CSS/JS: `index.html` renders `projects.js`, and `projects.json` holds the same data.
- The ↗ buttons open each project's live site.
- Drag-and-drop moves, sticky notes and export are saved only in your own browser.

Some personal projects are summarized in this public view.
